# 🧭 КОМПАС ПО ЖИЗНИ (Life Compass) v1.1

Алгоритмы для развития. Не советы — действия.

## 5 модулей
- 🎯 **Призвание** — археология истинных желаний
- 😊 **Счастье** — диагностика блоков
- 🔄 **Привычки** — система идентичности (66 дней)
- 💰 **Деньги** — финансовая ОС
- ⚡ **Ответственность** — система обязательств

## Уникальные фичи v1.1
- **Cross-module** — ответы из одного модуля влияют на рекомендации в другом
- **Трекер прогресса** — ответы сохраняются, строятся тренды
- **Цикл дня** — хронобиология в реальном времени
- **Ежедневное задание** — 1 конкретное действие из последнего решения
- **66-дневный трекер** — привычка формируется по науке
- **Мотивация** — персонализированные фразы по прогрессу

## Технологии
- PWA (offline-first)
- Service Worker
- Локализация RU/EN
- Адаптивный дизайн
- Cross-module аналитика
