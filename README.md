# 🧭 КОМПАС ПО ЖИЗНИ (Life Compass) v3.0

**Алгоритмы для развития. Не советы — действия.**

Интерактивный гид по 8 сферам жизни, который помогает находить решения, а не просто даёт советы. Каждый квиз — это диагностика, а каждое решение — это конкретный план действий.

---

## 📋 Модули (8 сфер)

| Модуль | Категории | Описание |
|--------|-----------|----------|
| 🎯 **Призвание** | passion, skills | Археология истинных желаний и карта навыков |
| 😊 **Счастье** | blockers, energy_audit | Диагностика блоков и энергоаудит |
| 🔄 **Привычки** | habits | Система идентичности (66 дней) |
| 💰 **Деньги** | audit, os | Финансовая ОС и аудит бюджета |
| ⚡ **Ответственность** | commitments, planning | Система обязательств и планирование |
| 🧘 **Здоровье** | nutrition, sleep | Протоколы питания и сна |
| 🗣️ **Отношения** | conflicts, family | Навык конфликта и семейные ритуалы |
| 🎨 **Творчество** | channel | Творческий канал и возвращение к детству |
| 📚 **Обучение** | reading, techniques | Чтение как привычка и техники обучения |

## 🚀 Уникальные фичи v3.0

### 🧠 Глубинные вопросы (Слой 2)
Каждый квиз содержит вопрос о **цене игнорирования** — что будет, если ничего не менять. Это создаёт осознанность и мотивацию.

### ⏰ Follow-up через неделю
Через 7 дней после прохождения квиза появляется **проверка прогресса**. Система спрашивает: «Что ты сделал?» и даёт награду за действие.

### 🧭 Identity-framing
Вместо «попробуй» — **«Ты — наблюдатель»**, **«Ты — строитель»**, **«Ты — инвестор»**. Ты не пробуешь — ты действуешь.

### 📊 Чёткая сегментация решений
**3–5 решений + 1 fallback** с чёткими conditions. Никаких псевдо-fallback'ов. Каждое решение имеет:
- Время выполнения (time_estimate)
- Ожидаемый результат (yield_estimate)
- Пошаговые шаги (steps)
- Предупреждения (warnings)
- Ресурсы (книги, техники)
- Ежедневное действие (daily_action)
- Follow-up через неделю

### 👤 Персонализация
- Приветствие по имени
- Инсайты в ленте времени (Timeline)
- Вызов дня (Daily Challenge)
- График прогресса за неделю
- Адаптивные рекомендации на основе кросс-модульных данных

### 🌍 Полная локализация

- Английский 🇬🇧
- Легко расширяется

### 📱 PWA (Progressive Web App)

- Установка на телефон

- Тёмная и светлая тема

## 🎯 Как это работает

1. **Выбери модуль** на главной странице
2. **Ответь на вопросы** квиза (обычно 5-7 вопросов)
3. **Получи решение** с конкретными шагами
4. **Выполняй ежедневное действие** из решения
5. **Через неделю** система спросит о прогрессе
6. **Отслеживай прогресс** в ленте инсайтов и графике
